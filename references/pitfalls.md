# 已知地雷與對策

| 現象 | 原因 | 對策（已內建或手動處理） |
|---|---|---|
| 流程卡住不動、出現「崩潰報告」視窗 | CAD 開某張圖時當掉，COM 呼叫會永遠等下去 | 已內建：每張圖在子行程以獨立 CAD 執行個體處理並設逾時，逾時只結束本次新開的 CAD 程序，自動重試一次。仍失敗就在 Excel 列為「需人工比對」 |
| 同一張圖每次都當掉 | 圖檔本身有 CAD 讀不了的物件 | 請使用者用 CAD 手動開啟後 AUDIT／RECOVER、另存新檔，再重跑；或改用人工比對 |
| 標示這一步逾時 | 變更物件太多，逐一改色（COM 約 0.05 秒／個） | 已內建：逾時依物件數自動延長（600 秒＋0.15 秒×物件數） |
| PDF 模型分區頁全空白 | 圖檔存檔時停在 3D 視角，視窗出圖座標被當成視圖座標 | 已內建：出圖前切回平面視圖（唯讀開啟，不存檔） |
| PDF 出成直式或縮在中間一點點 | 圖紙名稱與旋轉角度搭配錯，或模型範圍太大（例如各樓層上下排開） | 已內建：圖紙名稱用「寬×高」、旋轉 0；模型空間依標示位置分區出圖 |
| 視窗出圖報「參數無效」 | 還沒設視窗就先把出圖方式改成「視窗」 | 已內建：先設範圍 → 指定視窗 → 再改成視窗出圖 |
| PDF 是彩色或全黑、沒有紅色 | CTB 沒裝到 CAD 出圖型式資料夾；或圖檔用具名出圖型式（STB） | 加 `--install-ctb`；STB 圖檔會在 Excel 備註註明 |
| 每張圖都被判「圖號、圖名改了」 | 圖框裡的欄位（Field），DWG 只存最後一次更新的快取值 | 已內建：有 ACAD_FIELD 的文字不比 |
| Revit 匯出的結構圖差異多到不合理 | 匯出時圖塊名稱、填充邊界的起點與方向每次都不同 | 已內建：圖塊只比內容；填充邊界先正規化（去掉共線點、不論起點和方向）再比 |
| AutoCAD 報「被呼叫端拒絕」 | AutoCAD 忙碌時拒絕 COM 呼叫 | 已內建：`cadcom.call()` 自動重試 |
| env_check 顯示「類別未登錄」 | CAD 安裝不完整，或 32／64 位元不符 | 修復安裝 CAD，或改用另一套 CAD |
| AutoCAD LT | LT 沒有 ActiveX／COM 自動化 | 無法支援，需完整版或 BricsCAD |
| 標示 DWG 的 xref 找不到 | 原圖說本來就缺檔，或用了絕對路徑（例如 `Z:\`） | 不影響標示；回報時說明是原圖說的問題 |
| 「新版資料夾沒有此圖」很多 | 新版只發了改過的圖，或沒附某些專業的圖 | 不等於刪除；回報時要講清楚 |

## 修改程式後
- 改 `diffeng.py`／`make_pairs.py` 要跑 `tests/` 底下的測試，全部 PASS 才算完成
- CAD 程序清理：只結束本工具啟動的 CAD（由主視窗取得 PID）與執行期間新出現的崩潰報告視窗；使用者自己開的 CAD 不受影響
- AutoCAD 路徑只在 BricsCAD 上實測過；COM 介面相同，但 AutoCAD 第一次使用時請留意 log
